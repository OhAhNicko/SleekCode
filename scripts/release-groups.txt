# Commit groups for the next release. Read by scripts/release.sh.
#
# FORMAT
#   A line with NO leading whitespace is a commit subject.
#   Lines indented by 2+ spaces are paths belonging to the subject above them.
#   Blank lines and # comments are ignored.
#
# RULES
#   - Replace every <describe>. The release REFUSES to run while one remains.
#   - A path may appear in only one group (first wins).
#   - Dirty paths you leave out are fine: they land in a final sweep commit.
#   - Paths that are missing, clean, or gitignored are skipped silently, so a
#     slightly stale manifest still works.
#   - Order here is the order the commits are made in.
#
# Several files carry work from more than one workstream (SettingsPane, lib.rs,
# types/index.ts, App.tsx). Each is filed under the stream that dominates its
# diff — SettingsPane and lib.rs both go to NexusMind, which is where most of
# their new lines are.
#
# DIRECTORY ENTRIES CARRY NO TRAILING SLASH. release.sh skips any path that
# `git check-ignore` claims, and this repo's .gitignore is CRLF: its "blank"
# lines are really the pattern `\r`, which a trailing-slash path matches. So
# `src/lib/knowledge/` silently reports as ignored and falls out of its group
# into the sweep commit, while `src/lib/knowledge` does not. Verified 2026-08-08.
